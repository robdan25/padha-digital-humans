# PADHA Landing Page

Temporary landing page for PADHA - Fuel for Digital Human Avatars.

## Project Stack

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone https://github.com/robdan25/padha-digital-humans.git

# Step 2: Navigate to the project directory
cd padha-digital-humans

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The app will be available at http://localhost:8080

## Development

```sh
# Start dev server with hot reload
npm run dev

# Build for production
npm build

# Preview production build locally
npm preview
```

## Deployment

Build the project:
```sh
npm run build
```

The `dist` folder contains the production-ready files ready for deployment to Hostinger or any web host.
